A slope that tells you
before it moves.

SlopeGuard reads four sensors on your Arduino, compares them against limits you choose, and switches the node from a green light to a red light and buzzer when the ground looks unsafe.

This browser has no Web Serial. Open the page in Chrome or Edge, or use the demo.

Check your sensors

Each sensor should show a live reading. Hold the node still, then set the tilt baseline: every tilt reading is measured from it.

Baseline is set automatically from the first readings.

Set a safe limit for each sensor

Crossing any single limit raises the alarm. The marker under each slider is the live reading.

Combine sensors

Landslides rarely have one cause. A pair rule raises the alarm only when both sensors cross their own, usually gentler, limits at the same time.

Ready to watch the slope

The alarm needs two bad readings in a row and clears after six good ones, so one noisy sample won't trip it.
